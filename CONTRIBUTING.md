# Contributing

All contributions are welcome, especially test cases for MCP configuration formats and improvements to explainable drift warnings.

- Open an issue for major changes.
- Keep the tool local-first, offline, and read-only.
- Never commit real API keys, tokens, or identifiable private configs.
- Run `python -m unittest discover -s tests -v` before a PR.
- Add tests for new behavior and keep baseline compatibility in mind.
